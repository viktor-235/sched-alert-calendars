Not working?

Click Copy link and add the link in your calendar app by hand:

  • Google Calendar — on a computer, open Add calendar from URL and paste the link. On a phone there's a known issue: the link opens the Google Calendar app, which can't add a calendar by URL. Instead, type calendar.google.com in the browser's address bar, turn on Desktop site in the browser menu, then Other calendars → + → From URL. The calendar then appears in the app too; if it doesn't, turn on Sync for it in the app's settings. Google refreshes it with a delay, usually from a few hours to a day.
  • Apple Calendar — on a Mac: File → New Calendar Subscription; on an iPhone: Settings → Apps → Calendar → Calendar Accounts → Add Account → Other → Add Subscribed Calendar.
  • Outlook — Add calendar → Subscribe from web.
